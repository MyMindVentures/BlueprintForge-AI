# Roadmap

## BlueprintForge AI

This roadmap describes the intended build direction for the open-source project.

---

## Phase 1 — Premium UI Foundation

Goal: turn the seed app into a premium dark-theme SaaS command center.

Scope:

- app shell
- sidebar navigation
- top command bar
- mobile bottom navigation
- dashboard layout
- design tokens
- reusable premium cards
- status badges
- loading and empty states

---

## Phase 2 — AI Product Architect Workspace

Goal: create the workspace where raw app ideas become structured product documentation.

Scope:

- brainstorm input interface
- AI chat / prompt composer
- project context panel
- generated architecture preview
- template selector
- AI run states

---

## Phase 3 — Object Documentation Canvas

Goal: build the structured product documentation editor.

Scope:

- object index
- editable document canvas
- object inspector
- role/capability references
- AI/automation references
- validation issue markers
- section locking
- regenerate section action

---

## Phase 4 — Builder Build Pack

Goal: give builders implementation-ready documentation.

Scope:

- build pack overview
- implementation sequence
- component map
- data model draft
- API outline
- acceptance criteria
- AI coding prompt
- milestones

---

## Phase 5 — Company Launch Partner Flow

Goal: build the company-facing opportunity and bid system.

Scope:

- confidential invite
- teaser page
- 9-day bid room
- bid input
- qualification checklist
- highest qualified bid UI
- launch partner agreement placeholder

---

## Phase 6 — Revenue Recoupment & Split Dashboard

Goal: visualize company bid recoupment and 40/30/30 revenue participation.

Scope:

- winning bid amount
- recouped amount
- remaining recoupment
- progress ring/bar
- inactive/active split state
- Creator 40 / Builder 30 / Company 30 visual

---

## Phase 7 — Competitive Intelligence & Evidence

Goal: support market intelligence and protected access evidence.

Scope:

- similarity score UI
- feature advantage UI
- checked sources section
- Star Concept label
- access log timeline
- evidence package builder
- watermark preview

---

## Phase 8 — Backend, Auth & Persistence

Goal: add real persistence and user roles.

Scope:

- auth
- database models
- role-based access
- projects
- documents
- product objects
- company campaigns
- bids
- access logs
- exports

---

## Phase 9 — Production Readiness

Goal: prepare the app for serious use.

Scope:

- security review
- responsive QA
- accessibility pass
- performance optimization
- environment configuration
- deployment docs
- error handling
- test coverage where relevant

---

## Current focus

The current priority is:

1. premium UI foundation
2. AI Product Architect workspace
3. Object Documentation Canvas
4. Builder Build Pack

These areas best demonstrate the project vision and help attract quality contributors.
