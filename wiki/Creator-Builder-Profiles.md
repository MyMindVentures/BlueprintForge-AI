# Creator & Builder Profiles

## Purpose

BlueprintForge AI should help creators and builders discover each other.

The app should show both:

- the people who generate app concepts;
- the people who can build them.

---

## Creator Profile

A creator profile should show:

- name
- avatar
- tagline
- bio
- niches of interest
- app concept portfolio
- daily challenge issues posted
- GitHub/social links
- public proof badges
- creator thinking style

---

## Builder Profile

A builder profile should show:

- name
- avatar
- GitHub username
- bio
- tech stack
- AI coding tools used
- preferred challenge tracks
- portfolio links
- availability
- merged PRs
- completed issues
- trusted contributor level

---

## Discovery features

The app should support:

- browse creators
- browse builders
- filter by skills
- filter by challenge track
- follow creator
- follow builder
- mark interest
- invite builder to collaborate

---

## Trust levels

Suggested builder levels:

1. Public Contributor
2. Trusted Contributor
3. Core Contributor Candidate
4. Private Build Candidate
5. Official Builder Partner

---

## Important rule

Open-source contribution does not automatically create revenue-share rights or access to private app opportunities.

Deeper collaboration is earned through trust, quality, communication, and consistency.
