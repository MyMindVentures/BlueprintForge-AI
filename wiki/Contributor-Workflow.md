# Contributor Workflow

## How builders contribute

BlueprintForge AI is designed for builders to prove their skills through real contributions.

---

## Standard flow

1. Fork the repository.
2. Pick an issue.
3. Comment that you want to work on it.
4. Create a branch.
5. Build the feature or fix.
6. Open a pull request.
7. Add screenshots or demo if UI-related.
8. Respond to review feedback.
9. Get merged.

---

## Claiming an issue

Comment:

```txt
I want to work on this.
```

If you need clarification, ask before building.

---

## Good PR behavior

A strong PR:

- is focused;
- explains what changed;
- includes screenshots for UI work;
- checks mobile/tablet behavior;
- avoids private data;
- uses safe mock data;
- follows the premium dark UI direction.

---

## Builder reputation

Contributors may stand out through:

- merged PRs;
- clear communication;
- high-quality UI;
- clean architecture;
- fast execution;
- ability to follow product vision;
- ability to improve documentation.

---

## Private collaboration boundary

Contributing does not automatically grant revenue-share rights or access to private app opportunities.

Top contributors may be invited into deeper private collaborations later.
