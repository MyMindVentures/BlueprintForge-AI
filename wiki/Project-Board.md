# Project Board

## Purpose

The GitHub Project board should make the BlueprintForge AI build process visible and easy to follow.

The board should show daily challenges, active work, pull requests, review status, and launch priorities.

---

## Recommended columns

Use these project columns:

1. **Inbox** — new ideas and unrefined issues
2. **Daily Challenges** — issues posted at 07:30
3. **Ready for Builders** — well-defined issues builders can pick up
4. **In Progress** — claimed or actively worked on
5. **Pull Request Open** — PR submitted
6. **Needs Review** — maintainer review needed
7. **Merged / Done** — completed work
8. **Later** — good ideas, not urgent

---

## Recommended fields

If using GitHub Projects custom fields, add:

- Priority: Low / Medium / High / Urgent
- Area: UI / AI Architect / Build Pack / Company Bid / Revenue / Profiles / Docs / Deployment
- Difficulty: Beginner / Intermediate / Advanced
- Track: A-H
- Status
- Target Phase

## Daily workflow

Every day at 07:30:

1. Creator posts a new daily issue.
2. Issue receives `daily-challenge` and `builder-wanted` labels.
3. Issue is moved to Daily Challenges / Ready for Builders.
4. Builders can fork the repo and submit PRs.
5. Merged PRs move to Done.

---

## Manual setup note

If the project board is not yet created, create it manually in GitHub:

1. Go to the repo.
2. Open the **Projects** tab.
3. Click **New project**.
4. Choose **Board** or **Table**.
5. Add the columns and fields above.
6. Link issues from this repo.
