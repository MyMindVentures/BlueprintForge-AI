# GitHub Project Board

## Purpose

The GitHub Project board should make BlueprintForge AI easy to build in public.

It should show what is planned, what builders can pick up, what is in progress, and what has been shipped.

---

## Recommended board columns

### 1. Inbox

New ideas, unreviewed issues, rough concepts.

### 2. Daily Challenges

Issues posted by the creator at 07:30.

### 3. Ready for Builders

Clear issues that builders can claim and implement.

### 4. In Progress

Issues currently being worked on.

### 5. Pull Request Open

Work submitted and waiting for review.

### 6. Review / QA

PRs or features being checked for quality, mobile, UI, and product alignment.

### 7. Shipped

Merged and completed work.

### 8. Later

Good ideas that are not priority yet.

## Builder workflow on the board

1. Builder finds issue in Ready for Builders.
2. Builder comments: `I want to work on this.`
3. Maintainer confirms or gives guidance.
4. Builder opens PR.
5. PR moves to Pull Request Open.
6. Maintainer reviews.
7. Merged PR moves to Shipped.
