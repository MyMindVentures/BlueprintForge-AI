# Contributing to BlueprintForge AI

Thanks for your interest in contributing to **BlueprintForge AI**.

This project is an open-source builder challenge for creating an AI-native platform that turns raw app ideas into protected blueprints, builder build packs, company launch partner bids, and revenue-share app opportunities.

---

## How to contribute

1. Fork the repository.
2. Read the product vision and challenge docs.
3. Pick an open issue or challenge track.
4. Create a feature branch.
5. Build a focused contribution.
6. Submit a pull request.

---

## Recommended branch naming

Use clear branch names:

```txt
feature/premium-app-shell
feature/builder-build-pack
feature/company-bid-room
fix/mobile-navigation
ui/revenue-recoupment-widget
docs/product-vision-update
```

## Contribution types

You can contribute through:

- frontend components
- premium UI design
- responsive mobile/tablet layouts
- AI Product Architect features
- object documentation logic
- builder build pack UI
- company bid room UI
- revenue dashboard widgets
- documentation
- issue refinement
- architecture suggestions
- bug fixes

---

## Pull request expectations

A good PR should include:

- a clear title
- a short explanation of what changed
- screenshots or video for UI work
- notes about mobile/tablet behavior
- linked issue if available
- no secrets or private data
- focused scope

Avoid huge PRs that change unrelated areas.

---

## Design expectations

The UI should feel premium, dark, high-tech, and SaaS-grade.

Aim for:

- dark surfaces
- strong contrast
- polished spacing
- reusable components
- responsive layouts
- clean animations
- high-quality widgets

Avoid:

- generic dashboards
- low-contrast text
- random colors
- clutter
- cheap neon overload

See: `docs/UI_DESIGN_DIRECTION.md`

---

## Product boundaries

The platform itself is open source.

Future private app opportunities, confidential niche blueprints, real company prospect lists, real bid data, private legal templates, private revenue data, and protected customer/company information are not automatically open source.

Do not add private or sensitive data to this repository.

---

## Contributor levels

This project may recognize contributors informally through levels:

### Level 1 — Public Contributor

Contributes issues, documentation, UI fixes, bug fixes, or small features.

### Level 2 — Trusted Contributor

Has multiple accepted PRs and communicates clearly.

### Level 3 — Core Contributor Candidate

Helps shape architecture, reviews work, or contributes major modules.

### Level 4 — Private Build Candidate

May be invited into future private app opportunities.

### Level 5 — Official Builder Partner

May become part of future revenue-share builds.

Contributing to this open-source project does not automatically grant rights to private app opportunities, confidential documentation, future revenue-share projects, or protected business data.

---

## Code quality

Please aim for:

- readable code
- reusable components
- clear names
- type safety where possible
- responsive behavior
- accessible UI states
- no unnecessary dependencies
- no hardcoded secrets

---

## Communication

Be respectful, clear, and constructive.

Good contributors explain:

- what they built
- why they built it that way
- what tradeoffs they made
- what remains unfinished

---

## Questions

Open a GitHub Discussion or issue if you are unsure where to start.

Best first contribution: pick a challenge track from `docs/BUILDER_CHALLENGE.md` and create a focused PR.
