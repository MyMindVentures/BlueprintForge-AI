# Contributing to BlueprintForge AI

Thank you for considering a contribution to BlueprintForge AI.

BlueprintForge AI is an open-source Architect + Builder challenge. The Architect brings product concepts, system logic, documentation, monetization thinking, and challenge direction. Builders help turn that structure into real software.

## What this project is

BlueprintForge AI exists to help raw ideas become structured blueprints, builder-ready tasks, and real products.

It is especially designed for:

- creators with strong app concepts;
- neurodiverse thinkers;
- non-coders with product vision;
- builders who want clear, meaningful projects;
- designers, AI engineers, frontend developers, backend developers, and docs contributors.

## How to contribute

1. Read the README and docs.
2. Pick an open issue.
3. Comment that you want to work on it.
4. Fork the repository.
5. Create a focused branch.
6. Build the smallest useful version.
7. Submit a pull request with screenshots, notes, or a short demo.

## Contribution types

You can contribute through:

- UI implementation;
- frontend components;
- backend architecture;
- AI workflow design;
- documentation;
- issue refinement;
- accessibility review;
- security review;
- testing;
- product thinking;
- community building.

## Pull request expectations

A good PR should include:

- clear summary of what changed;
- linked issue number;
- screenshots for UI work;
- notes about mock data or assumptions;
- no secrets or private information;
- small, focused scope.

## Important boundaries

Contributing to the open-source repo does not automatically grant:

- private blueprint access;
- revenue-share rights;
- company bid room access;
- confidential product documentation;
- active build partner status.

Those deeper roles require explicit approval, agreements, and access grants.

## Tone of the project

Be serious, kind, clear, and builder-friendly.

This project is about turning different strengths into collaboration:

- The Architect brings vision and structure.
- The Builders bring execution.
- Together, ideas become living products.
