## 🚀 What is BlueprintForge AI?

BlueprintForge AI is a meta-platform for app creation.

It is designed to help creators turn raw app ideas into structured product blueprints, then transform those blueprints into build-ready documentation for developers, AI coding agents, and launch partners.

The platform combines:

- **AI Product Architect** — converts messy ideas into structured app documentation.
- **Object-based app specs** — compresses roles, screens, capabilities, flows, AI systems, monetization, access rules, and business rules into clean product objects.
- **Builder Build Packs** — gives builders implementation-ready documentation instead of vague ideas.
- **Protected blueprint layers** — controls what different users can see at each trust level.
- **Company launch partner bidding** — lets selected companies bid to become exclusive launch partners.
- **9-day bid windows** — creates urgency for company launch opportunities.
- **Bid recoupment** — winning company recoups its accepted bid first from future net revenue.
- **40/30/30 revenue participation** — after recoupment, future net revenue is split between creator, builder, and company launch partner.

## 🧠 Why this exists

Many people have app ideas. Very few can turn those ideas into structured, build-ready product systems.

BlueprintForge AI exists because ideas alone are fragile:

- builders need clear documentation;
- companies need a reason to commit;
- creators need protection and upside;
- AI coding agents need precise specs;
- product ideas need structure before they can become real apps.

This project is open source so builders can fork the repo, contribute through pull requests, and prove their skills through real work.

The best contributors may later be invited into deeper private collaborations, future app opportunities, and revenue-share builds.

## 🏗️ Core product vision

BlueprintForge AI should eventually support this complete flow:

1. Creator enters a raw app idea.
2. AI Product Architect extracts the product structure.
3. The app creates compact object-based documentation.
4. Sensitive content is split into protected blueprint layers.
5. Builders receive build-ready documentation through a Builder Build Pack.
6. Selected companies receive confidential opportunity invites.
7. Companies bid during a 9-day launch partner window.
8. The highest qualified bidder becomes the launch partner.
9. The builder builds the app using the approved Build Pack.
10. Revenue first recoups the company bid.
11. After recoupment, revenue is split: Creator 40%, Builder 30%, Company 30%.

## 🛠️ Local setup

Current seed app is based on an AI Studio / Gemini project.

### Prerequisites

- Node.js
- npm
- Gemini API key

### Run locally

```bash
npm install
```

Create `.env.local`:

```bash
GEMINI_API_KEY=your_gemini_api_key_here
```

Run the dev server:

```bash
npm run dev
```

## 🧠 Important project boundary

The platform itself is open source.

Future private app opportunities, confidential niche blueprints, real company prospect lists, real bid data, private legal templates, private revenue data, and protected customer/company information are **not automatically open source**.

In short:

> The machine can be open source. Future private opportunities created with the machine can remain protected.
