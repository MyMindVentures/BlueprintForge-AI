# Open Builder Challenge

## BlueprintForge AI

BlueprintForge AI is an open-source AI-native platform for turning raw app ideas into protected blueprints, builder build packs, company launch partner bids, and revenue-share app opportunities.

This challenge is for builders who want to help create the platform and show their skills through real GitHub contributions.

---

## The challenge

Fork the repo, pick a track, build something useful, and submit a pull request.

This is not only about building one app. It is about proving whether we can collaborate on a system that can generate, protect, fund, and build many future app opportunities.

---

## Who this is for

This challenge is for:

- frontend developers
- full-stack developers
- AI builders
- no-code/low-code builders
- product-minded developers
- UI designers who can code
- SaaS builders
- open-source contributors

## How to submit

1. Fork the repo.
2. Create a branch for your track.
3. Build your contribution.
4. Open a pull request.
5. Include screenshots or a short demo if UI-related.
6. Explain what you built and what remains unfinished.

---

## PR checklist

Your PR should include:

- clear title
- linked issue if available
- what changed
- screenshots or demo for UI work
- mobile/tablet notes
- known limitations
- no secrets
- no private data

---

## Evaluation criteria

Contributions are evaluated on:

- product understanding
- UI quality
- code quality
- responsiveness
- simplicity
- reusability
- communication
- ability to follow the vision
- ability to ship focused work

---

## Important boundary

This open-source repo is for building the BlueprintForge AI platform.

Future niche app blueprints, company lists, confidential campaigns, private legal templates, real bid data, and private opportunity documents are not automatically open source.
