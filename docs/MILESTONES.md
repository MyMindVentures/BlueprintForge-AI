# GitHub Milestones

## Purpose

Milestones organize BlueprintForge AI into clear build phases so builders know where each issue belongs and what the project is trying to ship next.

Use these milestones in GitHub Issues.

---

## Recommended Milestones

### M0 — Repo & Community Foundation

**Goal:** Make the repository feel like a serious open-source builder hub.

**Includes:**

- README
- contributing guide
- issue templates
- PR template
- security policy
- code of conduct
- wiki/docs
- project board setup
- labels
- first daily issues

**Definition of done:**

- Repo has all core open-source files.
- Builders know how to contribute.
- Issues and challenge docs are clear.

---

### M1 — Premium UI Shell & Online Launch

**Goal:** Get BlueprintForge AI online quickly with a premium dark high-tech interface.

**Includes:**

- landing page
- app shell
- sidebar
- top command bar
- mobile navigation
- dark theme tokens
- reusable premium cards
- public builder challenge CTA
- deploy to Vercel or similar

**Definition of done:**

- App is publicly online.
- Mobile layout works.
- GitHub repo and challenge CTAs are visible.
- UI feels premium and not generic.

## Manual GitHub setup

To create milestones manually:

1. Open the GitHub repo.
2. Go to **Issues**.
3. Click **Milestones**.
4. Click **New milestone**.
5. Copy each title and description from this document.
6. Save.
7. Assign existing and future issues to the correct milestone.
