# Creator & Builder Profiles

## Purpose

BlueprintForge AI should help creators and builders discover each other, learn how each other thinks, and collaborate through real product opportunities.

The platform should not only show app concepts. It should also show the people behind the concepts and the people capable of building them.

---

## Why this matters

The creator wants to prove that they can continuously generate strong app concepts and product improvements.

Builders need to see:

- who the creator is
- what kind of ideas the creator makes
- how structured the creator thinks
- what app opportunities exist
- how serious the platform is

Creators need to see:

- who the builders are
- what skills they have
- what they already contributed
- what kind of UI/code quality they deliver
- whether they communicate well
- whether they may be trusted for deeper collaborations

---

## Creator Profile

### Purpose

A creator profile shows the person or team generating app concepts and product opportunities.

### Suggested fields

- display name
- avatar
- short bio
- location/timezone
- creator tagline
- idea style
- niches of interest
- app concepts created
- public concepts
- daily challenge issues posted
- GitHub profile
- social links
- credibility notes
- portfolio proof
- revenue proof badges, if approved

### Suggested widgets

- Creator Signal Card
- App Concept Portfolio
- Daily Challenge Feed
- Public Proof Badges
- Creator Thinking Style
- Top App Opportunities

---

## Builder Profile

### Purpose

A builder profile shows who can build app opportunities and how they contribute.

### Suggested fields

- display name
- avatar
- GitHub username
- short bio
- tech stack
- AI coding tools used
- preferred contribution tracks
- availability
- portfolio links
- merged PRs
- open PRs
- issues completed
- challenge track history
- trusted contributor level
- builder reputation notes
- public comments/testimonials

### Suggested widgets

- Builder Skill Card
- Contribution History
- GitHub Activity Widget
- Challenge Track Badges
- Trusted Contributor Level
- Build Quality Score
- Communication Score

---

## Creator/Builder Discovery

The app should include a discovery experience where creators and builders can find each other.

### Suggested features

- browse creators
- browse builders
- filter builders by skill
- filter builders by challenge track
- show recent contributors
- show top contributors
- show builders interested in a concept
- show creators with active opportunities
- follow creator
- follow builder
- comment on profile
- invite builder to private opportunity

---

## Trust Levels

Suggested builder trust levels:

### Level 1 — Public Contributor

Can work on public issues and submit PRs.

### Level 2 — Trusted Contributor

Has multiple accepted PRs and communicates clearly.

### Level 3 — Core Contributor Candidate

Can help shape architecture or review work.

### Level 4 — Private Build Candidate

May be invited into private future app opportunities.

### Level 5 — Official Builder Partner

May become part of future revenue-share builds.

---

## Product rules

- Public profile data should be editable by the profile owner.
- Internal trust notes should remain admin-only.
- GitHub contribution data can be public if sourced from public repo activity.
- Revenue-share invitations are not automatic.
- Contributing to the open-source project does not automatically grant rights to private app opportunities.
