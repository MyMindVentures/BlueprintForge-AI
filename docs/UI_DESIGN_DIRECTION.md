# UI Design Direction

## Premium dark high-tech SaaS UI

BlueprintForge AI should feel like a premium AI-native command center for app opportunities.

It should not look like a generic dashboard.

---

## Visual mood

The UI should feel:

- premium
- intelligent
- high-tech
- cinematic
- founder-grade
- builder-friendly
- enterprise-ready
- secure
- polished
- fast
- modern
- AI-native

Avoid:

- boring SaaS templates
- low contrast text
- childish gradients
- random colors
- cheap neon overload
- cluttered dashboards

## Key pages

### Command Center

A futuristic operating dashboard with active opportunities, bid windows, builder build packs, protected views, revenue recoupment, AI runs, competitive intel, evidence alerts, and high-priority actions.

### AI Product Architect Workspace

A premium AI console with raw input, AI chat, extraction progress, architecture preview, template selector, validation score, and document generation actions.

### Object Documentation Canvas

A structured document editor with object index, document canvas, inspector panel, lock controls, validation issues, and section regeneration.

### Builder Build Pack

A developer-ready handoff interface with object map, implementation sequence, component map, data model, API outline, acceptance criteria, and AI coding prompt.

### Company Bid Room

A confidential B2B deal room with teaser, 9-day countdown, bid input, launch partner benefits, qualification checklist, and confidentiality status.

### Revenue Recoupment Dashboard

A visual dashboard showing winning bid, recouped amount, remaining recoupment, split inactive/active state, and 40/30/30 distribution.

### Competitive Intelligence

AI market intelligence dashboard with similarity score, market gap score, feature advantage, checked sources, and Star Concept label.

### Protected Access & Evidence

Security-focused UI with access logs, watermark preview, agreement status, evidence package builder, and monitoring alerts.

---

## Mobile and tablet rules

- Mobile-first where possible.
- No horizontal overflow.
- Use bottom navigation on mobile.
- Tables should become cards.
- Keep bid room, build pack, canvas editor, and dashboards usable on mobile.
- Touch targets should be at least 44px.

---

## Copy tone

Use:

- protected opportunity
- builder-ready documentation
- highest qualified bid
- company launch partner
- revenue participation
- bid recoupment
- based on checked sources
- access logged
- agreement-backed access

Avoid:

- guaranteed revenue
- guaranteed legal proof
- this app definitely does not exist
- we will sue automatically
- investor/shareholder wording unless legally structured
